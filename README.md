# Experiment No. 9
## Customer Segmentation Using K-Means and Hierarchical Clustering

### Aim
To implement K-Means Clustering and Hierarchical Clustering algorithms to segment shopping mall customers based on Age, Annual Income, and Spending Score.

### Objectives
- Perform data preprocessing and Exploratory Data Analysis (EDA).
- Apply feature scaling to the dataset.
- Determine the optimal number of clusters using the Elbow Method.
- Implement K-Means Clustering.
- Implement Hierarchical Clustering.
- Plot the Dendrogram to identify clusters.
- Visualize different customer segments.
- Compare both clustering techniques.
- Generate useful business insights from customer segments.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- Jupyter Notebook / Google Colab

### Dataset
**Mall Customer Segmentation Dataset**

Features used:
- Age
- Annual Income (k$)
- Spending Score (1–100)

### Algorithms Used
1. **K-Means Clustering:** Groups customers into clusters based on similarity and distance from cluster centroids.
2. **Hierarchical Clustering:** Groups customers into a hierarchy of clusters using a dendrogram.

### Methodology
1. Load the customer dataset.
2. Perform data cleaning and preprocessing.
3. Conduct Exploratory Data Analysis.
4. Scale the selected features.
5. Find the optimal number of clusters using the Elbow Method.
6. Apply K-Means Clustering.
7. Apply Hierarchical Clustering.
8. Plot the Dendrogram.
9. Visualize and analyze customer segments.
10. Compare both clustering techniques and derive business insights.

### Expected Outcome
- Identify different customer groups based on their spending behaviour.
- Understand customer purchasing patterns.
- Compare K-Means and Hierarchical Clustering.
- Help mall management develop targeted marketing strategies and promotional offers.

### Conclusion
Customer segmentation using K-Means and Hierarchical Clustering helps identify groups of customers with similar characteristics.
These insights can help shopping mall management improve marketing strategies, customer engagement, and loyalty programs.
